# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Two audiences with equal weight:
- **Non-technical owners and staff** (small business, B2C): want agents handling WhatsApp, e-mail, ERP (Omie) and recurring chores, without learning technical concepts. Served by the "Simples" mode.
- **Technical professionals** (devs, IT): build teams of agents that write and run code on their own machines. Served by the "Enterprise" mode.
One Ripper per person, installed on their own computer; also used from the phone (PWA, QR pairing planned).

## Product Purpose
A team of AI agents that actually does work: each agent has its own computer, memory, routines and connectors. Success = the person delegates real tasks and only steps in to approve what matters. North star: be better than Grok Bot.

## Positioning
- **Each agent has its own computer** (isolated Docker machine) and acts for real: runs code, browses, handles files.
- **A team that works on its own:** routines, group chats, agents calling each other; the owner approves external actions (send, publish, pay) from the Caixa.

## Operating Context
Runs locally (Node server + web UI). The person brings their own AI subscription (Claude, ChatGPT, API key) or uses local models. Main surfaces: Início, Caixa (inbox of approvals/alerts), Agentes, conversations (1:1 and groups), Projetos, Fluxos/Rotinas, Biblioteca, Conectores, Configurações.

## Capabilities and Constraints
- Light and dark themes; Simples vs Enterprise modes.
- External actions need approval; turns resume after restart; automatic backups.
- Undecided: hosting a relay for phone access outside the home.

## Brand Commitments
- Name **Ripper**. Interface voice in plain **PT-BR**, no technical jargon on user-facing surfaces.
- Owner's stated feel (06/10/2026): safe, easy to use, direct, simple, but scalable; minimal and focused on use, no clutter.

## Evidence on Hand
No customers, testimonials or benchmarks yet. Do not fabricate any.

## Product Principles
1. Each screen has one main job; details appear on demand.
2. Trust is visible: the person always knows what agents did and what waits for approval.
3. Plain words over technical terms.
4. Works the same for one agent or a hundred.

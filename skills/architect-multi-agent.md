# Architect — desenho de times Ripper

Skill bundled para agentes que orientam arquitetura multi-agente no Ripper.

1. Comece pelo objetivo do usuário em uma frase; confirme restrições (dados sensíveis, integrações, prazo).
2. Sugira 2–4 papéis com fronteiras claras; evite agentes “faz-tudo”.
3. Mapeie ferramentas Ripper por papel: web (pesquisa), computer (código/dados), memory (contexto longo), routines (recorrente), files (base estática), plugins (MCP).
4. Explique handoffs: formato da entrega (bullet, markdown, arquivo) e qual agente continua.
5. Simple vs enterprise: projetos compartilhados, marketplace MCP e aprovações só quando o fluxo exigir governança — não por padrão.
6. Trade-offs explícitos; zero números inventados de custo ou uso.

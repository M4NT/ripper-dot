Scope: Ripper app shell + Início (web/amostra.html sample). Mode: Operate.
Audience: non-technical owners and devs, equal weight. Job: see what each agent is doing, approve what waits, ask for something.

## Direction contract
THESIS: Each agent is a unit in a server rack with its own computer, LED and label plate; the screen answers "who is on, what are they doing, what needs me". Refuses the dashboard of stat cards + table.
OWN-WORLD: Light anodized aluminum ground (#eceeef), graphite unit faces (#1c1f23) with printed label plates, tiny LEDs (green on, amber waiting, red fault, dark off). Archivo; labels semi-condensed caps-free, tabular figures. 1px rules, no shadows except the pulled-out unit.
STORY: Visitor sees the rack, reads one-line status per unit, approves the amber one inline, opens a unit to talk.
FIRST VIEWPORT: Slim left rail; center column = rack titled by project with a single plain status sentence; units stacked edge to edge; right pane = selected unit's conversation; request bar fixed under the rack.
FORM: Server rack front panel, grounded #3 of 7 (reroll 1), seed 08c41f7d. Signature: selecting a unit slides it out like a drawer on rails.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
